      Ausgänge

      Noch kein Ausgang offen. Jedes Modul hat seinen eigenen Ausgang – Doppelklick im Ausgangsfenster = Vollbild.

      Weiter an Resolume, OBS, vMix, TouchDesigner
      • Projektor / LED / 2. Monitor: Ausgang auf den Bildschirm legen, doppelklicken → Vollbild.
      • OBS: Quelle „Fensteraufnahme“ → Ausgangsfenster wählen. Freistellen: Hintergrund Grün + Filter „Chroma Key“.
      • NDI für Resolume, vMix, TouchDesigner: OBS mit kostenlosem Plugin DistroAV → als NDI senden.
      • Spout (Windows): OBS + „Spout2 Plugin for OBS“.
      • vMix / TouchDesigner direkt: „Desktop Capture“ bzw. „Screen Grab TOP“ auf das Ausgangsfenster.
      Tastatur & Clicker

      → ↓ Bild ↓ Leertaste weiter · ← ↑ Bild ↑ zurück · B / . Blackout · F im Ausgang = Vollbild. Funktioniert auch, wenn ein Ausgangsfenster den Fokus hat.

      Sicherheit im Showbetrieb

      Alles wird laufend im Browser gesichert. Nach Absturz oder Neustart einfach die Datei wieder öffnen – Timer laufen weiter, Dateien und Einstellungen sind da, Ausgänge öffnest du mit einem Klick. Bildschirm-Captures müssen aus Datenschutzgründen neu gewählt werden.
